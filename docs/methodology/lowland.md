# พื้นที่ลุ่มต่ำ (Low-lying ground) — วิธีคำนวณ

**ชนิดของชั้นข้อมูล: ภาพประกอบ (illustrative)**
ชั้นนี้ **ไม่ใช่การตรวจวัด** ไม่ใช่การพยากรณ์ ไม่ใช่ค่าความน่าจะเป็น และไม่ใช่คะแนนความเสี่ยง
มันคือการอ่านรูปทรงของภูมิประเทศจากแบบจำลองความสูง (DEM) แล้ววาดว่า "ตรงไหนคือที่ต่ำ
เมื่อเทียบกับพื้นที่รอบ ๆ" เท่านั้น — ไม่มีตัวเลขใดในชั้นนี้บอกว่าน้ำจะท่วมที่ไหน เมื่อไร
หรือด้วยโอกาสเท่าใด

บนแผนที่จึงวาดเป็น **ลายเส้นทแยงสีม่วง พร้อมเส้นขอบสีม่วงเข้ม** ซึ่งไม่ใช่สีของน้ำ
ต่างจากพื้นที่น้ำท่วมที่ **ตรวจพบจริงจากภาพถ่ายดาวเทียม (GISTDA)** ที่วาดเป็น
**พื้นทึบสีน้ำ ขอบขาวจาง** — ความต่างนี้ตั้งใจให้แยกออกได้แม้ในภาพขาวดำหรือภาพที่พิมพ์ออกมา
ระยะห่างของลายเส้นวัดเป็นพิกเซลบนจอ ไม่ใช่ระยะบนพื้นดิน แปลงเล็ก ๆ (กว้างไม่กี่พิกเซล)
จึงยังเห็นลายสลับ ไม่กลายเป็นพื้นทึบซึ่งเป็นภาษาของข้อมูลที่ตรวจวัดจริง
เมื่อผู้ใช้เปิดชั้น **"ระดับการเผชิญน้ำ (ภาพประกอบ)"** (ปิดไว้เป็นค่าเริ่มต้น) จะมีลายทแยง
**กลับด้าน** ซ้อนลงบนลายนี้เฉพาะบางบริเวณจนอ่านเป็นลายตาราง — นั่นเป็นชั้นคนละชั้น
ที่วางทับอยู่ ไม่ใช่ค่าของพื้นที่ลุ่มต่ำที่เปลี่ยนไป (ดู [flood-exposure](/methodology/flood-exposure))

## ข้อมูลนำเข้า

- **ความสูงภูมิประเทศ (DSM) ~30 ม./เซลล์** — Copernicus DEM GLO-30
  © ESA / Copernicus Programme

ไม่มีข้อมูลตรวจวัดใด (ระดับน้ำ ปริมาณฝน ภาพดาวเทียม) เข้ามาในการคำนวณชั้นนี้เลย
ค่าที่เห็นจึงไม่เปลี่ยนตามสถานการณ์ และจะเหมือนเดิมทุกครั้งที่เปิดแผนที่จนกว่าชุดข้อมูล
ภูมิประเทศจะถูกสร้างใหม่

## ขั้นตอนการคำนวณ

คำนวณบนเครื่องของผู้ใช้ทุกครั้งที่เปิดจังหวัด (`apps/web/src/scene/hazardOverlay.ts`)
จากตาราง DEM ของจังหวัดนั้น:

1. **หาค่าเฉลี่ยของละแวก** — เฉลี่ยความสูงในหน้าต่างกว้างประมาณ 3,000 ม.
   (box blur สามชั้นเพื่อประมาณ Gaussian) ได้เป็น "ระดับพื้นโดยรวมแถวนั้น"
2. **หาความขรุขระของละแวก (σ)** — ส่วนเบี่ยงเบนมาตรฐานของความสูงในหน้าต่างเดียวกัน
3. **เทียบเป็น z-score** — `z = (ความสูงของเซลล์ − ค่าเฉลี่ยละแวก) / σ`
   โดยกำหนดพื้น σ ขั้นต่ำที่ 1.5 ม. เพื่อไม่ให้ที่ราบเรียบจริง ๆ ถูกหารด้วยเลขใกล้ศูนย์
4. **ให้น้ำหนักเฉพาะที่ต่ำกว่าละแวกตัวเอง** — เต็มค่าเมื่อต่ำกว่าค่าเฉลี่ยราว 1σ
   และหายไปเมื่อสูงกว่าค่าเฉลี่ยเล็กน้อย (`1 − smoothstep(−1.0, 0.15, z)`)
5. **จำกัดเฉพาะบริเวณที่เป็นที่ราบ** — คูณด้วย `1 − smoothstep(35 ม., 120 ม., σ)`
   ร่องเขาในภูเขาจึงไม่ติดขึ้นมา เพราะนั่นคือร่องน้ำ ไม่ใช่ที่ลุ่ม
6. **เกลี่ยให้เป็นผืนเดียวกัน** — box blur รัศมีประมาณ 350 ม. สองครั้ง เพื่อลดจุดกระจาย
   ที่เกิดจาก noise ของ DSM

ผลลัพธ์คือค่าต่อเซลล์ระหว่าง 0–1 ที่ shader ใช้กำหนดความเข้มของลายเส้น
(ช่อง R ของ overlay texture) ตั้งแต่ E10.4 ช่อง R เดียวกันนี้ยังเป็นตัวคุมชั้น
"ระดับการเผชิญน้ำ (ภาพประกอบ)" ด้วย — ตรงไหนที่ค่านี้เป็นศูนย์ ชั้นนั้นก็ไม่ระบายสี
ค่านี้เป็นค่าเชิงเปรียบเทียบภายในจังหวัดหนึ่ง ๆ
**ไม่ใช่ระดับความลึกของน้ำ ไม่ใช่ระดับเตือนภัย และเทียบข้ามจังหวัดไม่ได้**

## ข้อจำกัดที่ต้องรู้

- **DEM เป็น DSM ไม่ใช่ DTM** — Copernicus GLO-30 วัดถึงยอดสิ่งปกคลุม อาคารและเรือนยอดไม้
  จึงถูกนับเป็นความสูงพื้นดินด้วย ในเมืองหนาแน่นค่าจึงเพี้ยนได้
- **ไม่รู้จักสิ่งที่มนุษย์สร้าง** — คันกั้นน้ำ ประตูระบายน้ำ สถานีสูบน้ำ และการบริหารจัดการน้ำ
  ไม่ได้อยู่ในการคำนวณนี้เลย ที่ลุ่มที่มีคันกั้นน้ำกับที่ลุ่มที่ไม่มี จึงหน้าตาเหมือนกัน
- **ไม่มีเวลาเข้ามาเกี่ยว** — ไม่มีฝน ไม่มีระดับน้ำ ไม่มีน้ำขึ้นน้ำลง จึงไม่ควรอ่านว่า
  "ตอนนี้ที่นี่กำลังจะท่วม"
- **หยาบระดับ 30 เมตร** — คูคลอง ถนนยกระดับ และรายละเอียดย่อยกว่านั้นหายไปหมด

## จะดูข้อมูลที่ตรวจวัดจริงได้ที่ไหน

- **พื้นที่น้ำท่วมจากภาพถ่ายดาวเทียม (GISTDA)** — สิ่งที่ตรวจพบแล้วจากภาพชุดล่าสุด
- **สถานีวัดระดับน้ำ/น้ำฝน (ThaiWater สสน.)** — ค่าที่เครื่องมือรายงานมาโดยตรง
- **เรดาร์ฝน (กรมอุตุนิยมวิทยา)** — ภาพสะท้อนเรดาร์ย้อนหลัง 3 ชั่วโมง

สำหรับการตัดสินใจเรื่องความปลอดภัย ให้ยึดประกาศของหน่วยงานราชการเป็นหลักเสมอ

## เวลาที่แสดงบนแผนที่

ชั้นนี้ไม่มี "เวลาที่ดึงข้อมูล" (`fetchedAt`) เพราะไม่ได้ดึงมาจากบริการใดเป็นรายครั้ง —
มันถูกคำนวณใหม่จากชุดข้อมูลภูมิประเทศทุกครั้งที่เปิดจังหวัด legend จึงบอกตามจริงว่า
"คำนวณจากภูมิประเทศ ไม่มีการดึงข้อมูลรายครั้ง" แทนที่จะแสดงเวลาปัจจุบันหลอก ๆ

และถ้าชุดข้อมูลภูมิประเทศ (`terrain.bin`) ไม่ตรงกับลายเซ็น sha256 ที่ manifest ประกาศไว้
ชั้นนี้จะ**ไม่ถูกวาดเลย** พร้อมข้อความบอกเหตุผลใน legend — DEM ที่เชื่อไม่ได้ ไม่ควรผลิตค่าต่อ
ส่วนกรณีที่ manifest ไม่มีลายเซ็นให้ตรวจ ถือว่า "ยังตรวจไม่ได้" ซึ่งไม่เท่ากับ "ตรวจแล้วไม่ผ่าน"
ชั้นนี้จึงยังวาดตามปกติ (ดู `docs/dataset.md`)
